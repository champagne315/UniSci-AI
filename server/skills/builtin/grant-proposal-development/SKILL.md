# 科研项目申报

## 工作流

1. 提炼指南或任务书的目标、边界、评价标准、周期和硬性约束。
2. 将科学问题、研究目标、研究内容、技术路线和可验收指标逐层对齐。
3. 为每项任务补充已有基础、关键方法、里程碑、负责人、风险和替代路径。
4. 检查创新点是否可由现有技术差异和预期证据支撑，避免空泛措辞。
5. 做一致性审查：题目、摘要、目标、预算、计划、图表和预期成果应相互可追溯。

## 输出要求

- 先输出“目标—任务—指标”矩阵，再组织章节文字。
- 明确哪些内容是已有基础、拟开展工作和预期结果。
- 对未确认的指南规则或资源承诺用待核实项标记。
- 需要规划模板时读取 `references/grant-planning-matrix.md`。
