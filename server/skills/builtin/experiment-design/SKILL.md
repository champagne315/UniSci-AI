# 实验设计与验证

## 先定义可证伪目标

将宽泛目标改写为可被数据支持或推翻的假设，明确研究对象、干预、对照、观察窗口、成功阈值和停止条件。若关键前提不可测量，应先设计测量或先导实验。

## 工作流

1. 绘制因果或机制链，区分操纵变量、结果变量、混杂因素与边界条件。
2. 选择对照、重复、随机化、盲法和区组策略；说明每一项如何降低偏差。
3. 确定样本量、排除规则、缺失/失败处理和实验顺序，避免事后改写规则。
4. 为每个关键假设安排至少一个主要验证与一个备选验证。
5. 定义数据记录、质量控制、验收标准和复现实验路径。

## 输出要求

- 以“假设—设计—观测—判定—风险”结构交付。
- 明确哪些指标是主要终点，哪些仅用于探索。
- 对安全、伦理、设备限制或资源依赖给出前置条件。
- 需要设计审查时读取 `references/design-checklist.md`；需要记录实验时读取 `references/experiment-record-template.md`。
