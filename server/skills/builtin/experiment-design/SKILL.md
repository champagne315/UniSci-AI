# 实验设计工作流

提出方案时明确研究假设、自变量、因变量、对照条件、重复次数、随机化或盲法，以及潜在混杂因素。优先提出可复现且风险可控的步骤。

## 输出要求

1. 先写清研究问题与可检验假设。
2. 明确变量、对照、随机化、样本量和停止条件。
3. 列出主要偏差来源和缓解方式。
4. 需要检查清单时，阅读 `references/design-checklist.md`。
