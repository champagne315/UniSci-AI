# 文献综述工作流

当任务涉及文献或研究现状时，先检索可用知识库或公开网络。区分原始研究、综述与观点；引用时说明来源、证据强度和局限，不得虚构文献。

## 输出要求

1. 先给出结论摘要，再说明证据链和争议点。
2. 标注研究类型、样本或研究对象、发表时间与局限。
3. 证据不足时，明确说明需要继续检索的方向。
4. 若需系统性综述，可阅读 `references/evidence-checklist.md`。
