# 定向文献综述

## 先确认任务边界

在检索前确认研究问题、研究对象、时间范围、语种、证据类型、读者和交付物。范围不清时，先提出 3–5 个最关键的澄清问题；若用户要求直接推进，写明采用的检索边界和假设。

## 工作流

1. 把问题拆成对象、干预/方法、比较条件、结果指标与应用场景。
2. 制定检索式和来源优先级：系统综述/指南用于定位，原始研究用于支撑具体论断。
3. 记录每项证据的研究设计、样本或数据、条件、核心结果、局限与可迁移边界。
4. 按一致、冲突、不足三类组织证据；不得用论文数量代替证据强度。
5. 形成“已知—争议—缺口—下一步”的结论，并给出可继续检索的方向。

## 输出要求

- 先给结论摘要，再列证据表与争议点。
- 每个关键论断绑定来源；没有可靠来源时明确标注“待核验”。
- 区分相关、预测与因果结论，避免把体外、模拟或小样本结果过度外推。
