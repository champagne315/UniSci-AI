# 可复现性审查

## 工作流

1. 定义复现目标：重现数值、重跑分析、复现实验还是验证结论。
2. 审查输入材料、数据来源与版本、处理规则、随机性、环境、依赖和输出血缘。
3. 用阻断、重要、改进三级记录问题，给出最小修复动作与验收条件。
4. 对图表逐项追溯到数据、分析步骤、参数和脚本或操作记录。
5. 复核修复后是否可由独立人员在合理成本下完成目标。

## 输出要求

- 以审计报告而非泛泛建议交付，包含证据、影响、修复和验收。
- 区分“未提供记录”与“已证实不可复现”。
- 不得将代码可运行直接等同于研究结论可复现。
- 需要审计清单时读取 `references/reproducibility-audit-sheet.md`。
