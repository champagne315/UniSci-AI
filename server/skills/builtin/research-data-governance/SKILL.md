# 科研数据治理与血缘

## 工作流

1. 盘点数据资产、责任人、获取方式、敏感等级和允许用途。
2. 划分原始、清洗、分析和发布层，避免直接覆盖原始数据。
3. 建立数据字典：字段含义、类型、单位、允许范围、缺失编码和派生规则。
4. 为每次清洗、合并、筛选和派生变量保留可追踪变更记录。
5. 在交付前核对版本、血缘、质量规则、访问范围和归档材料。

## 输出要求

- 输出数据目录、字段字典、质量规则、变更日志与交付清单。
- 不能根据文件名猜测字段含义；不确定时提出待确认项。
- 对敏感数据只给最小必要信息，并注明访问与脱敏约束。
- 需要模板时读取 `references/data-governance-kit.md`。
