# 科研写作工作流

写作时先对齐目标读者、篇章结构和证据边界。将事实、解释与建议分开表达；没有来源支持的结论应明确标为假设或待验证项。需要写入工作区时，先说明拟生成的文件和内容用途。

## 输出要求

1. 先确认目标体裁、读者和字数范围。
2. 使用清晰的论点—证据—限制结构。
3. 不将未验证内容写成事实。
4. 需要结构模板时，阅读 `references/manuscript-outline.md`。
