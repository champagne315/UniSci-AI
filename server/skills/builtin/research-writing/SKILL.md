# 科研写作与论证

## 先定位写作任务

确认文体、目标期刊或读者、篇幅、语言、已有证据和交付阶段。未给出来源或数据时，只能提供结构、占位语与待补证据清单，不得编造结果、引用或实验细节。

## 工作流

1. 提炼全文的一句主张，并列出支撑主张的最小证据链。
2. 按背景—缺口—问题—方法—结果—解释—限制的逻辑组织段落。
3. 将观察结果、统计结论、机制解释与推测分层书写。
4. 逐段检查论点与证据是否匹配，删去无法支撑的强化措辞。
5. 最后检查术语一致性、图表引用、方法可复现性、限制与贡献的平衡。

## 输出要求

- 优先交付可审阅的提纲或段落，再给完整稿件。
- 每段只承担一个主要功能，首句说明段落目的。
- 对不确定、外推或因果表述使用与证据强度匹配的措辞。
