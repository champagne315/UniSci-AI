# 统计分析预案

## 工作流

1. 明确估计对象、目标总体、主要问题、主要终点与分析单位。
2. 定义分析集、协变量、分组、时间窗、异常和缺失值规则。
3. 为主要与次要问题匹配模型、效应量、区间估计与模型诊断要求。
4. 预先规定多重比较、亚组、敏感性与稳健性分析，区分确认性与探索性结果。
5. 写明样本量或精度依据、随机化/聚类结构及结果报告格式。

## 输出要求

- 对每个分析问题给出“输入—方法—假设—输出—解释边界”。
- 缺少参数时给出所需信息和可行的情景分析，而非伪造功效结果。
- 变更预案时保留原方案、变更原因和时间点。
