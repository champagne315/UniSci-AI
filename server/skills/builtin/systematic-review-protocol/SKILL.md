# 系统综述与证据合成

## 工作流

1. 界定综述问题、目标读者和协议范围；确定研究类型与时间/语种边界。
2. 预先写出纳入、排除、去重和冲突裁决规则，避免结果导向筛选。
3. 记录检索日期、来源、检索式和筛选流程，保留每个排除决定的理由。
4. 用统一字段提取研究特征、结果、偏倚风险与可比性。
5. 根据异质性决定叙述合成、分层比较或定量合成；证据不足时不得强行汇总结论。

## 输出要求

- 交付协议、筛选记录、研究特征表、证据结论与更新建议。
- 清楚区分“没有证据”和“证据显示没有效应”。
- 说明偏倚、异质性和证据确定性如何影响结论。
- 需要协议与提取表时读取 `references/review-protocol-template.md`。
