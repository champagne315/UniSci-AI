# 论断与证据核查

## 工作流

1. 将文本拆为独立、可核查的论断，标记其为事实、关联、因果、机制或预测。
2. 为每条论断定位直接证据，核对研究对象、条件、比较组、指标与结论范围。
3. 识别二手转引、引用不匹配、证据过时、从相关到因果跳跃和跨场景外推。
4. 按“保留、弱化、补证据、删除”提出最小修改建议。
5. 对关键论断输出可追溯的证据链与剩余不确定性。

## 输出要求

- 不评价作者或机构，只评价论断与证据匹配度。
- 用准确、可复查的引文信息；无法验证时标记为待核验。
- 避免用单篇研究支撑广泛或因果性结论。
- 需要审计表时读取 `references/claim-evidence-matrix.md`。
