# 数据分析与结果解读

## 先建立分析契约

明确研究问题、分析单位、目标总体、样本纳入规则、变量口径、数据版本和结论用途。没有数据或变量定义时，不虚构数值；先给出所需字段、检查步骤和分析计划。

## 工作流

1. 审核数据完整性：重复、缺失、异常、单位、时间窗口、分组泄漏和数据来源。
2. 定义主要结果、次要结果、协变量和分析集，区分探索性与验证性分析。
3. 按数据类型选择描述统计、比较、回归或预测模型，并写出关键假设。
4. 执行诊断与稳健性检查：残差/拟合、影响点、共线性、缺失机制、替代口径和分层结果。
5. 用效应量、区间估计和实际意义解释结果；显著性不等于重要性或因果性。

## 输出要求

- 先说明数据质量与适用范围，再给结果和限制。
- 每张表或图应回答一个明确问题，并标注样本量、单位、比较基准和不确定性。
- 将事实结果、解释和下一步假设分开表达。
- 需要完整分析结构时读取 `references/analysis-plan.md`；需要发布前检查时读取 `references/results-quality-check.md`。
