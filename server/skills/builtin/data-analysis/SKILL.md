# 数据分析工作流

先明确数据来源、样本范围、变量定义与缺失值处理，再给出分析方案。区分描述性结论与因果结论；不从未验证的数据中推断结果。

## 输出要求

1. 说明数据质量检查和变量口径。
2. 说明统计方法适用的假设和限制。
3. 将结果、解释与待验证假设分开表达。
4. 需要分析模板时，阅读 `references/analysis-plan.md`。
