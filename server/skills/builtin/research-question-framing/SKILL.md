# 科学问题与研究路线

## 工作流

1. 分离事实背景、真实约束、目标应用和待解释现象。
2. 用一句话界定研究对象、尺度、边界和拟解决的缺口。
3. 提出主假设与至少一个竞争假设，分别说明可观测证据与反证。
4. 设计最小可行验证：最少需要什么数据、实验或分析才值得继续投入。
5. 拆成探索、验证、扩展三个阶段；每阶段设置进入条件、退出条件和风险替代方案。

## 输出要求

- 输出问题陈述、假设—证据矩阵、最小验证方案和阶段路线图。
- 将未知前提、资源约束和价值判断显式列出。
- 不把研究目标写成无法被证据评价的口号。
- 需要结构化模板时读取 `references/question-canvas.md`。
