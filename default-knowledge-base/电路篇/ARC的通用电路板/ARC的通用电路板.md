# ARC的通用电路板

[ARC通用板安装说明\.pdf](图片和附件/ARC通用板安装说明.pdf)

**ARC通用板的故事**

最早得从盛泽楠进实验室开始说起。

我是2021年暑假进的232，当时已经有通用板了，我们学习电路焊接的时候就是用通用板作为教学材料。

听孙心悦学姐（19级）说，这个板子是沈煜韬和黄挺一起设计的，两位学长都是17级，并且都是做电路的，在通用板出现之前，俱乐部都是单车单板的状态，或者说使用的是面包板。

通用板的出现给俱乐部带来了哪些好处呢？首先它的体积很小，集成度很高，能实现的功能也很多。比如说它有4路的步进电机口，使用的是七特的驱动，8路舵机，4路红外传感器/超声波测距传感器，2个OpenMV接口，还留了一些引脚用于IO通信。

步进电机使用的是XL4005稳压调节12V电压供电，舵机使用的是XL4005稳压调节6V电压供电，Arduino和其他的5V用电器都是使用MP1584稳压进行供电。

有了通用板之后，每次开始备赛，一些传感器的测试、电机的测试、机构功能测试等就可以通过通用板完成。当所有的功能验证完毕，并且确定了机器人上到底应该有多少执行器之后，我们才会画一块专门针对于该车的特别的板子，因为通用板上往往存在冗余或是欠缺。

也确实是因为通用板设计得比较好，以至于从18级开始延续到19级、20级和21级，主要的车辆都是使用的通用板或者是通用板的改进板。整体电路的布局也是和通用板一样的，三个稳压输出三种电压，所有的东西都放在一块板子上，中间是Arduino，Arduino的下面是电池插口、开关、保险丝，两边是XL4005稳压以及对称的用电器。通用板给培训赛提供了很多的方便。

我记得我21年参加培训赛的时候拿到通用板我的第一反应是想搞明白它的结构，它本质上是一个把电池、稳压、单片机、用电器相互连接起来的接口板，但是对于当时的我来说，这已经是非常先进的技术，毕竟当时我连PCB都没有真实的接触过。

我开始研究板子的走线，形成了对于电路设计初步的一些认知，比如电池的正极引出导线到保险丝，保险丝引出导线到开关，开关分三路分别接到3个稳压的正极，3个稳压的负极汇到一起后输入回电池的负极。

12V稳压会给电机供电，功率一般比较大，正负极的电源线是沿着外侧走的，舵机基本也是同理，而Arduino布置在中间，Arduino的信号线就可以从中间往四周发散，这是一种非常合理的布局，可以算是从通用板上学来的一些更加底层的原则，即便现在我们已经在改进通用板了，我们在设计的过程中还是会坚持这些原则。

随着我们技术的不断进步，大概是从21级进俱乐部开始吧，我们逐渐有点感觉到通用板不太够用了，有哪些原因呢？

首先是用电器不够了，原先底盘的四个步进电机用于驱动轮子，上层的执行器我可以全部使用舵机来完成，循迹一般采用红外传感器。但是随着比赛难度的提高，单单使用舵机已经很难满足我们的需求，上层机构开始比较多的使用电机，这就导致一块通用板往往不够用，而增加步进电机大家一般就是再焊接一块通用板，焊接完成之后就需要实现两块板子之间的通讯，但是应该是IO通信总是存在一些问题，所以对于板子之间的通讯也提出了新的要求。

电机数量的不够是一个问题，还有一个问题是功率不足以及接口类型的不匹配。中农的比赛场地变得越来越大，使用七特驱动的42步进电机已经很难满足我们的需要，基本上要使用直流电机或者是57步进电机，而这就需要更换电机驱动。一般来说打比赛的时候肯定是先做底盘，但是现在连电路都没有（因为用新的驱动就意味着自己要重新先做一个电路板，但是车都没有，需要什么用电器都不知道，纯为了步进电机新做一个板子感觉很费时费力，这个事情就卡住了），底板就没法测试行走。

21年中农的时候，我们用的是直流电机，已经用上了新的直流电机驱动和大功率的稳压；22年中农的时候就已经开始使用57步进电机了，也是使用外接的大功率稳压；23年沿用22年中农的赛题也是57步进和大功率稳压。相当于已经逃不开使用别的型号的驱动和大功率稳压了，因为比赛场地大就导致车要做的更大，车更大就需要上更有力的电机，电机一大电流就会很大，我们在使用TB6600驱动的时候一般调节电流是3\.5A，四个电机就是14A，有接近160W的功率，这绝对是XL4005稳压所不能承受的。

挺好笑的是，XL4005稳压的额定电流只有5A，峰值8A，但是我们打比赛的时候经常就是4个电机都用XL4005稳压来供电，每个电机调节2A的电流就已经达到了小稳压的上限，所以基本每次比赛完，跑完两次全场，车子基本就得坏，因为小稳压带不动那么大功率的东西。23年ASABE奕炜他们的车子跑完之后小稳压就已经烫的很厉害了，22年ASABE翊哥他们的车子，机械臂的舵机都是一个小稳压驱动的，舵机的负载又很大，小稳压限流的时候舵机电压不稳定就会开始乱抖，这些都是稳压功率不够的问题。

由于比赛对于电机的功率要求越来越高，对于舵机的需求数量也越来越多，两个小稳压已经不足以胜任这些需求。并且由于驱动新的电机不能使用原来的驱动加上通用板上电机的接口数不够，所以每次比赛基本就得改板子，通用板就只能在ASABE和培训赛用一用。我是在2022年中农的时候做了一个外接大稳压并且使用TB6600驱动的板子，这个板子被好多组拿去用了，比如肖睿阳他们的车子用的就是我给的板子。

电机数量的问题、功率的问题、接口类型的问题其实就是第一代通用板的核心问题。除这些之外，比如对于巡线方式，原来都是使用红外传感器，但是由于路面干扰，我们目前会更倾向于使用超声波测距模块。或者是别的一些工业级的开关量传感器，至少那种1块钱一个的5V红外模块我们已经很少会用，它实在是太不稳定了。那么新的超声波传感器缺少接口，新的开关量传感器很多都是12V供电的，于是就又缺少接口。

还有一个问题是通讯方式，现在的232，使用串口通讯的情况会更多，甚至于我现在正在探索CAN通信，像RM他们基本用的都是CAN总线通信。但是这些Arduino用于串口通信的口原来并没有单独预留出来，而是作为了输入输出引脚。并且一些带有特殊功能（比如外部中断）的引脚也被简单当作了数字输入输出引脚，而他们本可以发挥更加重要的作用。

还有是1584的贴片稳压，贴片的小稳压不带散热本来功率就不高，单纯驱动Arduino其实是没有问题的，但是如果要外接OpenMV就显得有些不够了，小稳压在22年至23年这段时间里烧坏的还是比较多的，中农的草莓机器人坏过一次，后面思考了一下应该是一个Arduino加一个OpenMV已经超过了小稳压的额定输出了，长时间工作容易烧坏。

板子坏掉其实就又涉及到一个维修的问题。一般来说电路板没有真的哪一块是因为铜线被烧断而坏掉的，坏的东西其实大多就是稳压（由于短接或者功率过大而烧坏），但由于板子的设计，贴片稳压和XL4005稳压都是焊接上去的，非常的不好拆，除非你有4个人同时操作4把焊枪，一块板子坏了一个稳压就会报废，很多的板子大家也不会去检查到底是坏在了哪里，经常就是重新焊一个，导致实验室出现了很多的废板子，然后我也没那么多时间来修理，关键是修理了也几乎不会继续拿来使用。这里想说的就是板子的局部损坏导致的丢弃会造成器件的浪费。

还有一些比较小的问题，比如Arduino的小开关总是烧坏，保险丝和开关的焊接很麻烦之类的。

种种的迹象其实已经在告诉我们要换通用板了。旧的通用板不能满足比赛需求其实大家肯定能看出来，不过多数情况下大家只是根据自己的需要来做自己组的板子，没有人想到要给俱乐部重新做一个真正通用的板子，或者说，没有人想到要把大家的需求取一个并集。对于比赛倒是没什么，毕竟大家比赛总会自己做板子，但是我们培训赛就会缺少足够的材料。

所以，2024年培训赛的时候，我们的第二代通用板就出现了。

与其叫通用板，不如叫通用块。它把电源和接口分开了。首先底下有一个电源板，采用了四个稳压模块，我当时的想法是，一个大功率稳压用来驱动底盘的电机，一个大功率稳压用来驱动舵机，一个小功率稳压调12V给执行器的电机或者12V传感器供电，一个小功率稳压调节5V给Arduino、OpenMV、超声波传感器供电。至少这样一来功率问题一定是被解决了，电源板依然采用一个电池，电池连接开关。

我们选择把KCD1开关直接焊在板子上，这样真的很方便，不用拖着一根长长的开关线，但是也保留了外接开关的设计，如果有需要可以把开关接出去而不是用板上的开关。

然后关于保险丝，我们在电路板上使用了焊接式的保险丝座，这样就不用单独做线了，保险丝断了就直接换一个玻璃管保险丝就行。

这是两个小的改进，对于这两处改进需要感谢汪舒提供的建议，KCD1和保险丝座的封装都是他提供的。

然后小稳压我们选择了接插的方式，使用排母和插针进行连接，这样小稳压一旦坏了可以马上换一个新的，不需要通过电烙铁来拆，会方便很多，理论上就不会造成板子的浪费。

为了使得整个板子可以免费打样，电路板需要做到10cm\*10cm以内，所以大稳压和小稳压是层叠放置，大稳压扣在小稳压的上方，采用尼龙柱固定在电路板上。

四路调节好电压的供电通过XT30接口输送给上板，上板主要是Arduino和用电器的接口。板子设计的时候为了尽可能满足各种调试的需要（我们的目的是，一块板子能够让你完成所有的调试工作，甚至于这个板子就能够作为你的比赛板子，当然这样的话可能功能会有点冗余），上层一共安排了8路电机、12路舵机、6路5V传感器、4路12V传感器、6路超声波、3路串口、2路5V的供电给OpenMV用。

当然了直接这样连接的话，一个Arduino显然是不够的，所以我们采用了引脚复用的方式，这是一个全新的探索，虽然理论并不复杂。

一个大稳压只负责给6路大功率电机供电，一般底盘只用四个电机，且这四个电机肯定需要配置相同。一个电机需要3个引脚，那么对于这3个引脚，他会接在七特驱动、TB6600驱动和直流电机驱动上，一般来说用了七特肯定就不用TB6600，用了TB6600就不用七特。也就是说6路电机需要18个引脚，每路电机可以选择到底接入哪一种驱动，这三种驱动是共用引脚的，引脚复用算是该通用板的很大特色。车子需要使用的用电器肯定是有限的，但是不同的车可能需要不同的驱动，那么引脚就可以复用。

关于引脚的分配，这项工作是丢给许凌菘做的，但是设计这块板子的时候可能没有处理的很好，关于PWM引脚，应该只需要分配给电机的EN引脚就行，并且对于步进电机这是没用的，只对直流电机有效，这是一个问题；接着关于超声波和红外的引脚复用，选择了直接让红外传感器用4Pin口插在超声波传感器上，只不过只插3根线，感觉这也不是很好；中断的使用也有点不足，Arduino应该有6个内部中断，由于16、17引脚需要用于串口通讯，所以可用的其实有4个内部中断，应该利用起来；还有就是舵机全部分配在了A口上，实际使用过程中发现A11开始的引脚没法控制舵机，这是由于A口的本意是模拟输入口，它接了12位的ADC，有更高的模拟信号读取精度，所以有的口可能没法用于数字输出。

关于这款板子的PCB设计，主要是汪舒完成的。这里有很大的工作量，而我主要是这件事情的发起者，并且连结了很多人一起把新的通用板做出来。

设计上板接口的时候，汪舒直接把接口堆到了一起，缺少了一些布局上的思考，并且接口之间距离很近，没有办法在板子上直接看引脚号，导致每次接线的时候都需要拿一块新板子或者对着PCB图来看，不是很方便。但这主要是为了保证板子的尺寸不超10\*10，也是无奈之举，后面打算放弃追求面积小，而是把器件布局变得更合理。

不过至少这块板子是在培训赛开始之前凑吧凑吧完成了，我拿到样板之后也是自己马上焊接了一块，这个板子目前我自己有一直在用。它确实实现了我们的需求，就是功率够了，且接口的数量也够了，也能接很多不同的东西，只是在使用体验上还有一些欠缺。

总结下来大概有这样一些问题：

大稳压和小稳压的重叠放置导致小稳压坏了之后必须拆了大稳压才能更换（相当于需要多拆一些东西），其实使用上非常麻烦！

连接稳压输出和上板之间的线，采用XT30接口焊接工作非常费时费力，一共需要焊8个XT30接口，每个接口还要加热缩管，而且焊接手法上有一些讲究，不然上下板容易扣不上。

体积太大，主要是高度太高，没法很好的放在车上，一个大方块基本把主要体积都占掉了，并且肉眼可见的稳压之间的可用空间非常大，只是在当时不知道怎么合理安排稳压的位置。

有几个口不能控制舵机，上面提到的A口。

器件布局有点混乱，可以更加有条理一些。

总之小朋友们没有觉得这是一个很好的板子，可能是因为没有经历过我们之前的困境，或者说因为今年中农没有比，所以没有用上TB6600驱动，所以才觉得原来的通用板更好。这是因为在我们的ASABE选拔赛和培训赛上，对于小车的功率要求并不是很高，所以原有的通用板的问题没有怎么暴露出来。

很多组在ASABE选拔赛上没有采用我们的通用板，主要还是觉得体积太大，至于功能方面其实没那么看重。不过有些组在换了原来的板子之后，烧了好几个小稳压，这其实就是用电器功率太大了的缘故，所以大稳压还是很有道理的。总之就是说，由于体积太大，掩盖了通用板功能全面的优势，所以使用的人很少。

我自己也觉得它并不是最终形态的通用板，除了以上的一些问题之外，我也想把器件布局优化一下，以及把Arduino的硬件资源最大程度发挥出来，比如串口、中断、定时计数器之类的，舵机在控制引脚的时候会占用定时器，导致有一些引脚的PWM是无法使用的，这样的冲突也需要考虑，所以在着手更新之前，我看了很多关于Arduino的材料。

然后就是拖了好久之后，我终于开始一个人着手改板子，这是我们的第三代通用板。第三代通用板在功能和输出功率上和第二代没有太大的差异，着重优化了器件布局，并且缩小了体积。

我首先考虑电源板的器件布局。第二代的通用板上，小稳压是接在板子上的，大稳压是扣在小稳压上面的，这导致了整个电源板的高度很高。之所以当时把稳压模块堆到一起，是为了板子的整体尺寸能在100mm\*100mm以内，这样嘉立创可以免费打样。

如果四个稳压全部铺开放置的话，基本把整个电源板的面积都沾满了，开关、保险丝、其他接口会没有放置空间。

在设计第三代通用板的时候，我不太关心大小的问题了，因为第二代通用板的高度成了很多学生吐槽的问题，相比之下大小其实没有这么重要，而且即便是尺寸超了，嘉立创打样能贵多少钱呢？所以就没那么关心了。

我也注意到，其实稳压由于本来就是模块化的，尤其是大稳压，它是采用接线柱连接的，其实并不需要在PCB板上给它留一个大小一样的空间。所以我通过3D打印设计了一个固定大稳压用的零件，两个大稳压直接固定在3D打印零件上，这样的话整个电源板就不需要很大面积的PCB板了。PCB板上只留下电池输入给大稳压的插线接口，这样就极大减小了尺寸，现在的电源板PCB上有电池接口、保险丝、板上/外接开关、小稳压输出端插线接口、大稳压输入端插线接口，尺寸上满足嘉立创免费打样的要求。

顺便一提的是，关于电池的接口，我选择使用了XT60\-PW，这样电池可以横着插上去，使用体验上来说，插拔更加方便，也避免了一些导线和器件的干涉。

这块PCB板和两个大稳压一起被固定在3D打印件上，共同组成电源板。

关于3D打印件的设计，需要考虑到结构紧凑所以不能做的太大；固定大稳压的几个通孔需要抬高，因为稳压模块背部的焊接针脚是长一些的；PCB上也要留出孔位和3D打印件固定在一起，这种无实物的想象与设计，难度还是很大的。

大稳压由于出厂的时候安装的误差，两个大稳压放在一起的时候不能挨得太近，否则容易干涉。

当时设计的时候还有一些巧夺天工的地方。考虑到了如果把小稳压放置在同一侧，大稳压和小稳压的高度大约有30mm\.而另一边插线接口、保险丝这些还是挺低的，其实可以把Arduino焊在上板的下面，这样上下板扣到一起的时候，Arduino就可以把这部分空间占满，并且Arduino反过来焊之后，空出来的上板正面的位置可以放一些别的接口，空间利用率提高了。

这其实很困难，难在确定尺寸。Arduino的排母要焊在上板的PCB上，上板PCB和电源板上的尼龙柱固定，PCB上留的孔和3D打印件上留的孔还得能配合起来。插线接口、新的电源接口（XT60\-PW），这些都需要我自己重新画封装。

上板扣下去之后，Arduino应该正好在那些接线器件的上方，同时不能和大稳压以及小稳压之间有干涉。由于上板的接口密密麻麻，下板的稳压也设计得很紧凑，关于上下板之间怎么实现机械连接也是个问题，好不容易挤出了几个位置，做了三个尼龙柱用来固定上板和下板，尼龙柱数量少一点也方便拆。

从稳压输出的电，原来是通过XT30接口接到上板，之前说这里做线太麻烦，第三代的通用板改成了灰色的快插接头，就不需要专门焊接连接线了，并且购买这个接头也比XT30便宜很多。

第三代通用板在尺寸上比第二代小了一半，就和一个小的万用表一样，放在车上感觉也没有很大问题；电源板和接口板的连接做了优化，接线变得很方便；小稳压的调节专门留了孔，可以在组装完之后进行再次调节；Arduino用了C口版本，并且是侧面插线，比较方便；电池也是侧面插线，拔的时候不容易损坏板子。

为了榨干Arduino的硬件资源，我仔细读了它的手册，把串口、外部中断、I2C通信这些的功能都保留了下来，所有的电机都可以使用PWM调速，包括步进电机也可以，这个要感谢吕岳恒同学探索出来的，通过变频PWM控制stp引脚从而控制步进电机转速。

并且相较于第二代通用板，我对接口的布局做了全面的优化，所有的接口都是对称放置的，并且也增加了相应的功能说明，引脚也可以直接从板上看到了。

关于板子的布线，为了追求尽可能少的过孔，我进行了2次布线，从中也探索了一些布线经验，这个很难教，只能说一边布线一边思考。布线是一个很麻烦的事，一次布线搞了我6个小时。

从目前的测试结果来看，这个板子比较令人满意了，关于第四代和第三代板子的区别，主要是修改了步进电机的引脚安排，因为在次之前，我不知道变频PWM这件事，EN引脚接的是PWM，但后面吕岳恒探索了那个技术，所以现在STP引脚接的是PWM输出，直流电机还是不变的，此外增加了陀螺仪的接口。

另外也感谢陈奕憬同学制作的通用板焊接教程，在今年培训赛上会检验一下这份教程是否易懂，接着做一些修改。

个人感觉，这个板子已经是Arduino Mega的极限了，如果实验室继续使用Arduino，那么这个板子应该可以继续使用很久，但是更强大算力的东西比如树莓派和Nano应该也会被重新捡起来。但这个通用板依然可以用于底层控制。希望学弟学妹们某一天会意识到这个成果的来之不易吧，做这个东西真的花了很多精力和时间。

如果有可能，我觉得未来的小朋友应该要着手开始开发我们实验室自己的模块了，这会更有价值，把市面上一些常见模块的体积缩小一些，或者更加集成一下，如果继续使用成品模块，我觉得通用板的体积是没法减小了。



——盛泽楠 2025年6月20日 于家中
