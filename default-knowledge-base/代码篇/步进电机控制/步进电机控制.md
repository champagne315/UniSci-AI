# 步进电机控制

# 控制原理

> 从视频可以看出，步进电机通常是两相、四线、双极性（每一相可正反上电），我们用“拍”的方式理解步进电机的控制原理，从一相通电换接到另一相通电的过程称为一拍，显然一拍电动机转子转动一个步距角。
> 
> 

**波动模式（单四拍）**

![截屏2024\-08\-17 13\.32\.06\.png](图片和附件/截屏2024-08-17%2013.32.06.png)

这是最简单的步进电机驱动方式。这种方式，电机在每个瞬间只有一个线圈导通，消耗电力小。但在切换瞬间时没有任何的电磁作用在转子上，容易造成振动，也容易因为惯性而失步。

**全步模式（双四拍）**

![截屏2024\-08\-17 13\.36\.49\.png](图片和附件/截屏2024-08-17%2013.36.49.png)

这种方式输出的转矩较大且振动较少，切换过程中至少有一个线圈通电作用于转子，使得输出的转矩较大，振动较小，也比单四拍平稳，不易失步。

**半步模式（八拍）**

![截屏2024\-08\-17 13\.37\.54\.png](图片和附件/截屏2024-08-17%2013.37.54.png)

半步模式是波动模式和全步模式的组合，它使用单四拍和双四拍交替进行的方式，每传送一个励磁信号，步进电机前进半个步距角。其特点是分辨率高，运转更加平滑，也是最常用的一种方式；

**微步模式（十六拍及以上）**

![截屏2024\-08\-17 13\.40\.29\.png](图片和附件/截屏2024-08-17%2013.40.29.png)

可以看作是半步模式的增强版，因为它可以进一步减小步距，并且具有恒定的扭矩输出。这是通过控制每相流过的电流强度来实现的。与其他方案相比，微步模式需要**更复杂的电机驱动器。**假设IMAX是一个相位中可以通过的最大电流，则从图中左侧开始，在第一个图中IA = IMAX，IB = 0。下一步，控制电流以达到IA = 0\.92 x IMAX，IB = 0\.38 x IMAX，它产生的磁场与前一个磁场相比顺时针旋转了22\.5°。控制电流达到不同的电流值并重复此步骤，将磁场旋转45°、67\.5°和90°。与半步模式相比，它将步距减少了一半；但还可以减少更多。使用微步模式可以达到非常高的位置分辨率，但其代价是需要更复杂的设备来控制电机，**并且每次步进产生的扭矩也更小**。扭矩与定子磁场和转子磁场之间的夹角正弦成正比；因此，当步距较小时，扭矩也较小。这有可能会导致丢步，也就是说，即使定子绕组中的电流发生了变化，转子的位置也可能不改变。

![202305101722489\.png](图片和附件/202305101722489.png)

> 这几种模式分别对应着上图的信号模式，那么如何把控制器擅长的脉冲信号（高低电平按照一定的周期输出）转换成下图的信号呢？这就需要步进电机的驱动电路（或者说驱动器）。
> 
> 

**步进电机的驱动器**

> 驱动电路主要的任务就是两个：**脉冲分配和功率放大。**
> 
> 

**脉冲分配**

![IMG\_5117\.jpg](图片和附件/IMG_5117.jpg)

![IMG\_5118\.jpg](图片和附件/IMG_5118.jpg)

上图是一个三相六拍步进电机的驱动电路（与二相四拍的原理一致），脉冲分配主要是利用了D触发器的数字集成电路，在脉冲上升沿的时候对A、B、C分别控制，具体如何让A、B、C在不同的时刻出高电平或者低电平，需要等到学习完电工电子学的数字电路部分、能跟据数字电路图写出状态方程后才能明白，这里就不展开叙述了。总之，只要合理地设计数字电路，我们就能完成由单列脉冲到多列脉冲的控制。

**功率放大**

功率电子电路是一种以向**负载提供功率**为主要目的的电子电路，功率电子电路不仅要能输出足够大的电压，而且要能输出足够大的电流。所以不专业点说，功率放大就是为了放大电流，由于单片机输出的电流有限，或者说没有较强的带负载能力，所以需要对输入信号进行放大，具体的方式也不展开叙述，在电工电子学的功率电子电路一章中会详细的学习（这也是搞电力电子技术的人的专长）。

但是这里介绍一下电流对步进电机的影响：

![截屏2024\-08\-17 14\.13\.15\.png](图片和附件/截屏2024-08-17%2014.13.15.png)

简单说，通常情况下，**转速与感应电动势成正比**，**力矩与电流大小成正比**。提高电流对转矩的影响是非常明显的，但是也不能超过额定电流，往往我们发现电机的转矩不够时，首先要想到电流，再想到细分，最后再是速度的大小。（电流的调节方式在下面的使用说明书中有介绍）

**V\+和GND **步进电机驱动器的供电，我们通常用12V供电。

**COM\(Common\)** 公用接口，由于我们用的是微控制器，选用3\.3\-5V模式，采用共阳级接法，故将Arduino的5V电源线接进。

**DIR\(Direction\) **方向信号，高电平和低电平分别控制正转和反转（根据连线情况不同而不同）

**STP\(Step/Pulse\) **脉冲信号，上述脉冲信号即输入此处，脉冲间隔小，速度快。

**EN\(Enable\) **使能信号，高电平和悬空使能步进电机，低电平使步进电机脱机。

**细分 **对应上述的拍：

|波动模式或全步模式（单四拍或双四拍）|1细分|1\.8°|
|---|---|---|
|半步模式（八拍）|2细分|0\.9°|
|微步模式（十六拍及以上）|4细分及以上|0\.45°及以下|

“拍”是为了更好的理解驱动器的内部原理，以后我们只需要用细分去描述步进电机一个脉冲转动的角度，更高的细分，更小的转动角是为了更加精确的角度控制，同时也是为了步进电机更小的震动（稳定性），但是牺牲了一定的转矩以及速度（由于一个驱动器的脉冲的周期或是说频率是有高低限制的）。

# 控制方式

从上面的叙述我们已经知道，想要丝滑地控制步进电机，关键是输入给STP引脚的脉冲形式，脉冲周期的快慢决定着步进电机速度的快慢。

## 最基础最简单的控制方式

```C
void setup(){
    pinMode(22,OUTPUT); //DIR引脚
    pinMode(23,OUTPUT); //STP引脚
    pinMode(6,OUTPUT); //EN引脚
}

void loop(){
    digitalWrite(22, HIGH);
    digitalWrite(6, HIGH);
    for (int i = 0; i <= 200; i++){
        digitalWrite(7, HIGH);
        delayMicroseconds(300);
        digitalWrite(7, LOW);
        delayMicroseconds(300);
    }
}
```

## AccelStepper 库控制

可以去https://docs\.arduino\.cc/libraries/accelstepper/下载第三方库。

概括来说，AccelStepper库是利用micros做定时，当现在的时间与上一次时间的差值达到我的需求脉冲周期，做一次

```C
digitalWrite(7, HIGH);
delayMicroseconds(1);
digitalWrite(7, LOW);
```

这样一来，相当于一定时间发一个短暂的脉冲，可以提升CPU的运行效率，减少长时间Delay的阻塞影响。
