# 舵机控制

> 控制一个舵机，主要有以下几个步骤：电路连线，程序控制，零点复位。
> 
> 

1. **电路连线**

![image\.png](图片和附件/image.png)

舵机一般会有**正极、负极、信号**三根线。以上图所示的SG90舵机为例，棕色线是电源负极，需要接地；红色线为电源正极，需要接\+5V；黄色线为信号线，需要接到单片机的PWM引脚上。

|**舵机接线说明表**||||
|---|---|---|---|
|**舵机线颜色**|**对应功能**|**接线说明**|**Arduino连接示例**|
|红色|正极（VCC）|提供舵机电源（通常为5V）|稳压 5V 引脚|
|棕色|负极（GND）|接地，电源回路|开发板 GND 引脚|
|黄色|信号线（PWM）|接收控制信号（PWM脉冲宽度调制）|连接到支持PWM输出的引脚（如Arduino的A6、A8等）|

**请注意：**通常舵机需要的供电功率比较高，如果你需要控制1个以上的舵机，那么您必须使用单独的电源为舵机供电，而不能使用Arduion开发板的\+5V引脚，为1个以上的舵机供电。另外也请注意，如果使用独立电源为舵机供电，那么独立电源与Arduino必须共地（电源GND与Arduino的GND相互连接在一起）。

此外，三根线的颜色还可能有黑白白、黑黑白、黑白红等组合，具体可以查看淘宝的**商品详情页**或**技术文档**。但一般而言，颜色最深的线为负极，中间的线为正极线，剩下一根为信号线（**请一定以实际情况为准！**）。

**怎么连？**前文所展示的图片中，舵机线的接口都为原装的**杜邦头**，可以使用三根公对母的杜邦线直接连接到单片机上使用。但实验室中更多的舵机接口被改为了3Pin头，可以插在通用板的3Pin舵机接口上使用。

2. **程序控制**

> 下面是一段通用的舵机控制程序
> 
> 

```C++
#include <servo.h>                 //引入控制所需的库

Servo ARCservo;                    //定义对象

void setup(){
    ARCservo.attach(A8);           //连接到引脚
}

void loop(){
    for(i = 0; i < 180; i+=5){
        ARCservo.write(i);         //循环写入角度
        delay(500);
    }
    for(i = 180; i > 0; i-=5){
        ARCservo.write(i);         //循环写入角度
        delay(500);
    }
}                                  //期望是以10°/s的角速度往复旋转
```

**servo\.write\(\)**的参数范围是0\~180整型。如果是360°舵机或是270°舵机，则会将角度映射到0\~180。

3. **零点复位**

实际使用前，舵机还需要进行零点复位。这是因为舵机在未通电时可以被旋转，导致安装在机器人上的舵机在程序中的角度是一个未知的值。为了解决这个问题，应该现在程序中使用**servo\.write\(\)**函数为舵机写入一个角度，再安装到机器人上（实际使用过会有深刻体会）。
