# 带编码器的直流电机控制

> 下面是一段控制代码示例
> 
> 



```c++
// 电机驱动引脚配置
const int ENA = 8;    // PWM速度控制引脚
const int IN1 = 28;    // 方向控制引脚1
const int IN2 = 29;    // 方向控制引脚2

// 编码器引脚配置
const int ENCODER_A = 18;  // 编码器A相 (外部中断5)
const int ENCODER_B = 19;  // 编码器B相 (外部中断4)

// 全局变量
volatile long encoderCount = 0;  // 编码器计数值
unsigned long prevTime = 0;      // 上一次计算速度的时间
float rpm = 0;                   // 计算出的转速(RPM)

void setup() {
  // 设置电机控制引脚
  pinMode(ENA, OUTPUT);
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
  
  // 设置编码器引脚为输入
  pinMode(ENCODER_A, INPUT_PULLUP);
  pinMode(ENCODER_B, INPUT_PULLUP);
  
  // 附加编码器中断处理
  attachInterrupt(digitalPinToInterrupt(ENCODER_A), updateEncoder, RISING);
  
  // 初始化串口通信
  Serial.begin(115200);
  Serial.println("DC Motor with Encoder Test");
  
  // 设置初始电机方向
  digitalWrite(IN1, HIGH);
  digitalWrite(IN2, LOW);
}

void loop() {
  // 设置电机速度 (0-255占空比)
  analogWrite(ENA, 150);  // 中等速度
  
  // 每秒计算并显示转速
  if (millis() - prevTime >= 1000) {
    // 计算转速 (RPM = 计数/时间 * 60秒/转数)
    // 假设编码器每转产生20个脉冲 (根据实际编码器调整)
    rpm = (float)encoderCount / 20 * 60;
    
    Serial.print("Encoder Count: ");
    Serial.print(encoderCount);
    Serial.print("\t RPM: ");
    Serial.println(rpm);
    
    // 重置计数和时间
    encoderCount = 0;
    prevTime = millis();
  }
}

// 编码器中断服务函数
void updateEncoder() {
  // 读取B相信号确定方向
  int b = digitalRead(ENCODER_B);
  
  // 根据B相状态增加或减少计数
  if (b == HIGH) {
    encoderCount++;  // 正转
  } else {
    encoderCount--;  // 反转
  }
}
```

这段程序使用外部中断引脚读取编码器，并通过直流电机驱动驱动直流电机。

带编码器的直流电机一般有六根线，分别为：电机电源正负（12V），编码器电源正负（5V），编码器输出AB相。

直流电机驱动板一般有五根线与MCU相连，分别为5V供电正负，方向引脚IN1，IN2，使能引脚ENA。

通过IN1，IN2的状态控制电机正反转，ENA的占空比控制转速。驱动板一侧接入15V（12V）电源，通过OUT输出调制的驱动电压，连接到直流电机的电源正负极。

**PID控制**

尽管理论上直流电机的转速与电压成正比，但是因为内部齿轮摩擦，绕组素质，外部扭矩等因素的影响，直流电机实际的转速很可能与程序中写入的占空比并不成正比，需要动态调整。简单来想，可以设置一个期望的转速，再使用编码器读取一定时间内的脉冲数用来表征实际转速，如果实际转速小于期望转速，就提高占空比；反之降低占空比。为了科学的进行调整，可以引入PID算法进行控制。

PID算法分为三部分：比例（proportional）、积分（integral）、微分（derivative），例如：

```C++
int kP = 1;                //比例增益
int kI = 1;                //积分增益
int kD = 1;                //微分增益
int proportional;
int intergral;
int derivative;
int speed;                 //占空比
int error;
int pre_error;
int exp_rpm;               //期望速度
long time;
long pre_time;
long delta_time;

void loop() {
    time = millis();
    error = rpm - exp_rpm;                           //rpm需要通过前文的编码器得到
    
    delta_time = time - pre_time;
    proportional = error;                            //比例项
    intergral = intergral + error*delta_time;        //积分项
    derivative = (error - pre_error)/delta_time;     //微分项
    
    speed = kP*proportional + kI*intergral + kD*derivative;
    analogWrite(ENA, speed);
    
    pre_error = error;
    pre_time = time;
}
```

PID控制器的三个组成部分及其核心功能如下（每部分用一句话概括）：

1. **P（比例）**：**即时纠错** \- 根据当前误差大小直接输出控制力（误差越大，输出越强）。

2. **I（积分）**：**消除残留** \- 累积历史误差，专门消除系统长期存在的稳态误差（如持续偏移目标值）。

3. **D（微分）**：**抑制震荡** \- 预测未来趋势，通过误差变化率提前刹车，防止系统超调和振荡。



> 📌 形象比喻：  
> 
> - **P** 像方向盘：当前偏差越大，转向越急  
> 
> - **I** 像配重块：持续修正方向跑偏  
> 
> - **D** 像减震器：过弯时防止车身晃动
> 
> 



实际使用中，还需要稳定PID算法的执行频率，以及对积分项限幅。如何得到更精准、延迟更低的误差项是一个值得深入思考的问题，如何科学的调整三个增益也是一个值得深入思考的问题。
