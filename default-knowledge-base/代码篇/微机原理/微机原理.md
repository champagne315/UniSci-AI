# 微机原理

# 计算机及系统组成

## 计算机结构

计算机结构分为两大类：

1. 哈佛结构：程序和数据空间独立的体系结构，不仅采用不同的存储模块，还可以通过各自的总线进行访问。

2. 冯诺伊曼结构：程序和数据共享存储空间和总线

\(存储器不但能存放数据，也能存放指令，计算机具有区分指令和数据的能力）

## 指令系统

CPU通常为单个芯片，又称为微处理器，依据其使用的指令系统，分为复杂指令集（CISC）和精简指令集（RISC）

复杂指令集指令数目多而复杂，每条指令字长并不相等，电脑必须加以判读。典型的复杂指令集计算机架构有Intel的X86架构，被广泛用于个人电脑（PC）上。

精简指令集指令数目少，每条指令都采用标准字长、执行时间短、中央处理器的实现细节对于机器级程序是可见的。典型的精简指令集架构有ARM架构，被广泛用于移动设备（如平板电脑、移动电话、数字媒体）上，另外，苹果电脑Macbook如今使用的也是基于ARM的M系列芯片。

# 单片机的组成

单片机通常采用哈佛架构，ARM Cortex\-M内核的STM32系列采用精简指令集，Intel 8051单片机采用复杂指令集，我们常用的Arduino开发板的芯片为ATmega2560\-16AU，采用基于AVR的强化RISC架构。

对于我们制作机器人，采用精简指令集和复杂指令集的区别仅仅在于汇编语言层面上（两者的汇编指令不同），但是为了高效地进行嵌入式开发，我们肯定是采用高级语言进行编程，再通过编译器直接编译成机器码烧录进单片机。

这里可以岔开一嘴，汇编语言之所以被称为低级语言，是因为他每条指令是可以和0101的机器码直接地、一一地对应的，这也是为什么我们总是听说汇编语言执行效率很高。现在我们知道，编译器在将高级语言编译成机器码时就等价于将高级语言编译成汇编语言，但是在这个编译中会产生很多低效的机器码（或者称为汇编指令），举一个最简单的例子：

```Plain Text
a=3;b=4;c=a+b;
//将其编译为汇编语言(具体情况视编译器而定，这里举个例子）：
MOV AX, 03H
MOV BX, 04H
ADD AX, BX
MOV CX, AX
//自己直接编写汇编语言
MOV AX, 03H
ADD AX, 04H
MOV CX, AX
```

## 中央处理器

不同单片机的CPU的位数不同，分为8/16/32位，位数越高，处理能力越强。CPU是单片机的核心，用于完成运算和控制操作，包括运算器和控制器两部分的电路。

## 内部存储器

### 数据存储器，RAM

以80C51为例，内部数据存储器按照地址分为4个区域

```Plain Text
00H-1FH 寄存器区
20H-2FH 位寻址区
30H-7FH 用户RAM区
80H-FFH 特殊功能寄存器区域
```

由于80C51是8位的单片机，每个地址对应8位数据

每种单片机的存储器都不同（但是原理类似），所以这里只简单介绍数据存储器的四个区域

1. 寄存器区：也称为通用寄存器，用于存储数据。

2. 位寻址区：数据（字节）中的每一个位都具有地址，可直接对位进行操作。

3. 用户RAM区：用户可以在这里开辟堆栈，堆栈先进后出，后进先出，用于保护程序断点和数据。

4. 特殊功能寄存器：不同的寄存器（或者寄存器的位）控制不同的功能，有些用作累加器（做加法），有些用作溢出、进位、奇偶校验的标志位，有些用作指针。

### 程序存储器，ROM

用于存放程序（指令），以80C51为例，芯片内部有4K ROM存储单元，其地址为0000H\-0FFFH，有些地址为特殊单元，用于定时器、外部、串口的中断地址。

### 输入，INPUT

- **上拉输入模式：**IO内部接上拉电阻，此时如果IO口外部没有信号输入或者引脚悬空，IO口默认为高电平，如果IO口输入低电平，那么引脚就为低电平，MCU读取到的就是低电平。**但是，STM32的内部上拉是"弱上拉"，即通过此上拉输出的电流是很弱的，如要求大电流还是需要外部上拉。**

- **下拉输入模式：**IO内部接下拉电阻，此时如果IO口外部没有信号输入或者引脚悬空，IO口默认为低电平，如果IO口输入高电平，那么引脚就为高电平，MCU读取到的就是高电平

- **模拟输入模式：**当GPIO引脚用于ADC采集电压的输入通道时，用作"模拟输入"功能，此时信号不经过施密特触发器，直接直接进入ADC模块，并且输入数据寄存器为空 ，CPU不能在输入数据寄存器上读到引脚状态。当GPIO用于模拟功能时，引脚的上、下拉电阻是不起作用的，这个时候即使配置了上拉或下拉模式，也不会影响到模拟信号的输入输出

**TTL施密特触发器：**基本原理是当输入电压高于正向阈值电压，输出为高；当输入电压低于负向阈值电压，输出为低；**IO口信号经过触发器后，模拟信号转化为0和1的数字信号，也就是高低电平，并且是TTL电平协议，这也是为什么STM32是TTL电平协议的原因。**

### 输出，OUTPUT

- **开漏输出模式：**开漏输出模式下，通过设置位设置/清除寄存器或者输出数据寄存器的值，途经N\-MOS管，最终输出到I/O端口。这里要注意N\-MOS管，当设置输出的值为高电平的时候，N\-MOS管处于关闭状态，此时I/O端口的电平就不会由输出的高低电平决定，而是由I/O端口外部的上拉或者下拉决定；当设置输出的值为低电平的时候，N\-MOS管处于开启状态，此时I/O端口的电平就是低电平。同时，I/O端口的电平也可以通过输入电路进行读取；注意，I/O端口的电平不一定是输出的电平。

- **推挽输出模式：**推挽输出模式下，通过设置位设置/清除寄存器或者输出数据寄存器的值，途经P\-MOS管和N\-MOS管，最终输出到I/O端口。这里要注意P\-MOS管和N\-MOS管，当设置输出的值为高电平的时候，P\-MOS管处于开启状态，N\-MOS管处于关闭状态，此时I/O端口的电平就由P\-MOS管决定：高电平；当设置输出的值为低电平的时候，P\-MOS管处于关闭状态，N\-MOS管处于开启状态，此时I/O端口的电平就由N\-MOS管决定：低电平。同时，I/O端口的电平也可以通过输入电路进行读取；注意，此时I/O端口的电平一定是输出的电平。

## 时钟电路与时序

以80C51为例，芯片内部有一个高增益反向放大器，在芯片引脚跨接一个晶体振荡器和微调电容，从而构成一个稳定的自激振荡器，芯片内的时钟信号均是由该振荡器通过分频等电路提供的，例如51单片机的时钟脉冲信号是时钟电路产生的振荡脉冲经过触发器进行二分频之后得到的。

## 中断系统

中断是MCU非常重要的组成部分，我们去网上搜索，经常会以一个故事来比喻中断，这里也先用一个比喻来引入：

正常的单片机运行就好像我们去抄作业，一行一行地开始抄同桌的作业，我们要反复地把头凑过去看一行抄一行，在单片机里面也叫轮询（字面意思，一轮轮地询问），但是有了中断，就好比同桌在一旁给我们报答案，这样我们就不用频繁地转头，只要听同桌给我们报答案就可以。

**中断的定义：**由外设向CPU提出请求，在**满足一定条件**下，CPU暂停现有程序的运行，而去运行中断服务程序（中断子程序），执行结束后**返回原来的程序**继续运行。

要真正理解中断的内涵，最好还是要从汇编的角度来理解：

```Assembly language
//以80C51为例，这是一个典型的外部下降沿的计数器
ORG     0000H
SJMP    START
ORG     0003H
SJMP    IN

START:  SETB IT0
        SETB EX0
        MOV  A, #0
        SETB EA     //一些必要的标志位设置，相当于开启中断功能
WAIT:   SJMP WAIT   //相当于while(1){}
IN:     INC  A      //中断服务程序
        RETI
        
//下面来一步步看程序是怎么运行的 PC是程序指针     
ORG     0000H
SJMP     START
ORG     0003H
SJMP     IN

START:  SETB IT0
        SETB EX0
        MOV  A, #0
        SETB EA     
WAIT:   SJMP WAIT   (1)(3) <-- PC //在此处循环，当外部下降沿来到时
                    (2) (SP) <- PC SP = SP + 2 //将PC的值压入堆栈，保护现场
IN:     INC  A      (2) <-- PC
        RETI        (3) PC <- (SP) SP = SP - 2 //回到主程序
```

以上汇编的例程主要是让大家了解PC作为程序指针是怎么工作的，以及中断如何在这里面发挥作用，具体代码不要求掌握。

> 实际上，调用中断服务程序的过程类似于程序设计中的**调用子程序**，其主要区别在于调用子程序指令在程序中是事先安排好的；而何时调用中断服务程序事先却无法确知。因为中断的发生是由外部因素决定的，程序中无法事先安排调用指令，因而调用中断服务程序的过程是由硬件自动完成的。
>

### 外部中断

- **电平触发：**只要外部信号保持在特定电平，中断就会一直有效。

- **边沿触发：**只有在信号发生跳变（有高到低，由低到高）的时候，中断才会响应一次。

### 内部中断

1. 定时器中断

当定时器（计数器）计数到一定程度（可以设置）的时候，定时器溢出，触发中断信号，CPU运行中断服务程序。

2. 串行口中断

用于串口通信，由于Arduino没有严格意义上的串口中断，这里不展开，主要就是在串口接收或发送数据的时候可以产生串口中断。

## PWM 波输出

**脉冲宽度调制（PWM）**

**PWM（Pulse Width Modulation）信号是通过对一系列脉冲的宽度进行调制，等效出所需要的波形（包含形状以及幅值），对模拟信号电平进行数字编码，也就是说通过调节占空比的变化来调节信号、能量等的变化，****占空比****就是指在一个周期内，信号处于高电平的时间占据整个信号周期的百分比，例如方波的占空比就是50%。**

如果发送端用脉冲的占空比来传递“电压值”，也就是将某个数字的电压值对脉冲的占空比进行调制，就可以在接收端调制脉宽的数据流中得到需要的模拟电压值，从而达到DAC的目的。

![pwm\_1\.gif](图片和附件/pwm_1.gif)

如上图所示，假设脉冲的占空比为0的时候（整个周期全部为低电平）代表电压值为0，占空比为100%的时候（整个周期全部为高电平）代表电压值为最高电压，比如5V，则40%的占空比就是40%$\times$5V。占空比改变（每个周期的脉宽改变），也就意味着输出的电压值在改变。

![pwm\_2\.gif](图片和附件/pwm_2.gif)

我们甚至可以在一个周期内输出不同的脉宽，从而到达输出正弦波的目的（如上图所示），这也被称作SPWM。

在单片机中，我们可以用定时器进行PWM输出，也称为OC（Output Compare\)输出比较的方式进行PWM

![截屏2024\-05\-02 11\.29\.03\.png](图片和附件/截屏2024-05-02%2011.29.03.png)

**PWM周期由ARR决定，占空比由CCRx决定**

注意，上图是STM32的PWM输出原理图，Arduino的输出不区分ARR和CCR，他使用一个寄存器OCR在两种不同模式（CTC模式和PWM模式）下来进行脉冲输出。

## PFM 波输出

**脉冲频率调制（PFM）**

**PFM（ Pulse Frequency Modulation），是一种通过改变脉冲频率来控制输出功率的调制方式。**

PFM的概念用在设计开关电源芯片比较多，这里我们借用这个术语来表示输出不同频率的脉冲。

![image\.png](图片和附件/image.png)

如上图所示，PWM关心一个脉冲周期内高电平和低电平分别占有的时间，而PFM只关心一个周期是多长，高电平的时间保持不变。
